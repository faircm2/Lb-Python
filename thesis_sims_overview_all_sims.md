# Simulations for the thesis: scripts and parameters

Scanned from the local scripts, job scripts, batch scripts and result folders in `PythonLBCourse` (state 25 Oct 2026).
Values marked *(inferred)* come from script or job-script defaults and folder names, because the run folder has no `parameters.txt`.
Model names: both families are multiphase lattice Boltzmann models. The Inamuro scripts implement the Inamuro et al. 2003 scheme with a Cahn-Hilliard phase field (`F_CahnHilliard` in `Inamuro_Cap6.1`) and the Shan-Chen forcing term (`Shan-Chen - A=tau*n_dt` in the code; the file names say 'SchanChen'). The Zhang scripts implement Zhang et al. 2020: a conservative Allen-Cahn phase-field equation for the order parameter (distribution g_i, anti-diffusion term lambda) and the free-energy approach for the surface-tension force (F_s = mu_phi * grad(phi), with the chemical potential mu_phi of eq. 6), coupled to the pressure-velocity distribution f_i.
Common to all runs unless stated: channel width D = 1.0 mm, nu = 2.9e-6 m^2/s, rho_0 = 1000 kg/m^3, a = 1, b = 6.7, T = 3.5e-2 (Inamuro), interface width W = 4 (Zhang).

## 4. Points to settle before the thesis text

1. The 3D studies on sigma, tau_f and theta from `study/` ran with the f wall boundary before the correction of 24 October. At sigma 0.1 and above, and for theta below 90 in long runs, they are affected by the floor instability (sigma 1.0 collapsed at iteration 1,800, sigma 0.1 at about 22,500). They would need a rerun with Cap07 to be quoted.
2. The Cap04 (alpha) and Cap05 (sigma, tau_f) folders have no `parameters.txt`. Their values above come from script and job-script defaults and need your confirmation.
3. The experimental model so far is a flat-floor rectangular channel, not the herringbone geometry from the STL file.
